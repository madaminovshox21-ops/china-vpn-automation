# Mijoz jalb qilish matnlari (nusxa-joyla)

## 1. Upwork job'ga taklif (cover letter)

> Har bir e'longa moslab, birinchi jumlani o'zgartiring. Qisqa = yaxshi.

```
Hi [Name],

I read your post — you need [aniq muammoni takrorlang, mas: "a security review of
your Node.js API before launch"]. That's exactly what I do.

I'm a penetration tester who also codes, so I can both find the issues and fix them.
Here's how I'd approach yours:
1. Scope + written authorization (I only test what you approve).
2. Test for OWASP Top 10, auth/access-control, and business-logic flaws.
3. Deliver a clear PDF report: severity, steps to reproduce, and a fix for each.
4. Optionally implement the fixes and re-test.

I can start with a small fixed-price scope so you can judge the quality with low risk.

A quick sample of my work: [namuna hisobot PDF havolasi yoki GitHub].

When can we discuss scope?

Best,
[Ismingiz]
```

## 2. "Lead magnet" — bepul tekshiruv (bot orqali)

> LinkedIn/X/Telegram/e-mailda sovuq murojaat. Bot bepul passiv skani — ilinish nuqtasi.

```
Hi [Name],

I ran a free, non-intrusive surface check on [company] and noticed a few things
worth a look (e.g. missing security headers / no DMARC / SSL nearing expiry).

Nothing invasive — all from publicly available data. Want the full breakdown?
You can get an instant free report from my bot here: [BOT HAVOLASI]
(just send your domain — it only does deep checks on domains you verify you own).

If useful, I offer a full authorized pentest with fixes. No pressure either way.

Best,
[Ismingiz]
```

## 3. LinkedIn/X bio

```
Penetration Tester & Developer | I find security holes and fix them |
Free instant surface scan → [BOT HAVOLASI]
```

## 4. Bepul→pullik voronka (bot bilan)

```
Bepul passiv skan (bot)  →  PDF hisobot (ilinish)  →  "to'liq audit kerakmi?"
   →  engagement (yozma ruxsat)  →  faol pentest + tuzatish  →  oylik retainer
```

## Qayerda mijoz izlash

- **Upwork / Freelancer / Contra** — asosiy.
- **LinkedIn** — startaplar CTO/founderlariga sovuq murojaat + bepul skan.
- **Bug bounty** (HackerOne, Intigriti) — portfolio + qo'shimcha daromad.
- **Telegram/X** IT hamjamiyatlari — bot havolasini tarqating.

## Muhim qoidalar

- **Har doim yozma ruxsat** (engagement) — botdagi engagement funksiyasi shu uchun.
- Kichik pullik ishdan boshlang → sharh yig'ing → narx ko'taring.
- Har mijozdan **oldindan 50%**.
- Bepul skan faqat passiv (ochiq ma'lumot) — bu qonuniy va xavfsiz ilinish.
