# SentryScan — Sinash yo'riqnomasi

Bot ishga tushgach (`python -m bot.main`), Telegram'da **@SentryScanbot** ni oching va quyidagilarni sinang.

## 1. Asosiy oqim
- [ ] `/start` → xush kelibsiz + menyu. Siz admin bo'lgani uchun **⚙️ Admin panel** ham ko'rinadi.
- [ ] `/` bosing → buyruqlar menyusi chiqadi (start, shop, subscribe, mysub, verify, check, help).

## 2. Do'kon
- [ ] **🛒 Do'kon** → 4 mahsulot (⭐120–200).
- [ ] Bittasini tanlab, ⭐ to'lov oynasi chiqishini tekshiring (haqiqiy to'lov qilmasangiz ham bo'ladi).

## 3. Xavfsizlik tekshiruvi (asosiy)
- [ ] **🛡 Xavfsizlik tekshiruvi → 🔎 Passiv** → **o'z domeningizni** yuboring (masalan `example.com`).
- [ ] Hisobot keladi: SSL, header'lar, DNS, SPF/DMARC.
- [ ] **📄 PDF hisobotni olish** tugmasini bosing → PDF fayl keladi. ← buni skrinshot qiling, portfolio uchun.
- [ ] **🎯 Faol tekshiruv** → tasdiqsiz domenga → **rad etilishi** kerak (bu to'g'ri, himoya ishlayapti).

## 4. Domen tasdiqlash (o'z domeningiz bo'lsa)
- [ ] `/verify example.com` → **DNS-TXT usuli** → ko'rsatilgan TXT yozuvni domeningizga qo'shing.
- [ ] `/check example.com` → tasdiqlansa, endi **faol tekshiruv** ishlaydi.

## 5. Obuna (yopiq kanal bo'lsa)
- [ ] Yopiq kanal oching, **botni admin qiling** (invite users huquqi bilan).
- [ ] `/admin → 💎 Obuna rejalari → /addplan` → nom, narx, kanal ID kiriting.
- [ ] Bot obuna linkini beradi. `/subscribe` da tugma sifatida chiqadi.
- [ ] Linkni bosib, Telegram obuna oynasini ko'ring (to'lov, avtomatik qo'shilish).

## 6. Admin
- [ ] **⚙️ Admin panel → 📊 Statistika** → foydalanuvchi/sotuv/skan soni.
- [ ] `/addop <tg_id>` → operator qo'shish.
- [ ] `/addeng` → engagement (ruxsatnoma) yaratish.

## Muammo bo'lsa
Terminaldagi log (xato matni) yoki skrinshotni saqlang — tuzatish uchun kerak bo'ladi.
